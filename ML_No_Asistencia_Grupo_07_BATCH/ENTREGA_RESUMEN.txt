VERSION MODIFICADA - ANALISIS MASIVO POR SALON

Cambios principales:
1. Se conserva la interfaz de evaluación individual.
2. Se agregó carga de archivos XLSX/XLS/CSV desde Streamlit.
3. Se agregó autodetección de archivos colocados en data/entrada/.
4. Se agregó análisis masivo de todos los estudiantes del archivo.
5. Se agregaron alias de columnas comunes para facilitar la carga de Excel.
6. Se agregó resumen de estudiantes en riesgo alto, medio y bajo.
7. Se agregó exportación de resultados a Excel.
8. Se agregó edición manual del checklist para completar factores sociales que no están en el dataset.
9. Si no existe información del checklist, el sistema NO la interpreta como ausencia del factor.
10. Se agregó entrenamiento avanzado opcional desde un histórico con columna abandono.
11. El entrenamiento avanzado utiliza validación cruzada, GridSearchCV y VotingClassifier.
12. Se agregó la utilidad analizar_salon.py para ejecución por consola.
13. Se agregaron pruebas automatizadas para el análisis masivo.

Importante:
- Para predicción supervisada real se necesita un histórico con la columna abandono.
- Si no existe ese histórico, el sistema utiliza un score académico heurístico.
- El resultado es una alerta de riesgo y no una confirmación de que el estudiante abandonará.
