# Medidas preventivas y de mitigación

Los documentos de esta carpeta son configurables por el usuario. El sistema los carga según los factores detectados en estudiantes con riesgo medio o alto.

Estructura:

- `factores_academicos/`
- `factores_economicos_sociales/`
- `factores_violencia_proteccion/`
- `factores_geograficos_tecnologicos/`

Para modificar una medida, sustituya el DOCX manteniendo exactamente el nombre del archivo y su carpeta.

La aplicación no necesita cambios en Python para utilizar la versión actualizada del documento.

La interfaz presenta todas las medidas asociadas al estudiante seleccionado y permite descargarlas individualmente o en un único DOCX combinado.
